# UI Overhaul Plan

## 1. Design Philosophy
- **Simple & Symmetrical:** The UI will abandon overly complex layouts in favor of simple, box-based symmetry.
- **Light Theme Only:** The dark mode/dark colors will be removed. The application will focus on a clean, light aesthetic.
- **Gemini Brand Colors:** The primary color palette will utilize the premium Google Gemini brand colors (e.g., vibrant blues, soft purples, and ethereal gradients) on top of the clean white/light background. *Note: No generic colors will be used; all colors will be selected for a premium aesthetic.*

## 2. Initial Loading Screen (Greeting Animation)
- **Concept:** A clean, blank page featuring a greeting animation that cycles through "Namaste" and greetings in other languages.
- **Animation Feel:** 
  - Smooth and consistent transitions.
  - Pacing will be strictly balanced (the "sweet spot" — neither too fast to read nor too slow to cause impatience).
  - Will feature the Gemini brand colors seamlessly fading through the text or as a subtle background element.

## 3. Structural Guidelines (Box-Based Symmetry)
- **Layouts:** Use evenly spaced, balanced grids and symmetrical box cards for displaying content, forms, and features.
- **Borders & Shadows:** Subtle drop shadows with soft, rounded box borders to maintain a modern but simple and symmetrical look.

## 4. Technical Constraints
- The UI overhaul will be implemented using functional React patterns and strict TypeScript.
- Core UI logic (like the animation sequencer) will be accompanied by tests.
